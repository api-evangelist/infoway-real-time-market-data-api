# Infoway Real-time Market Data API

Real-time and historical financial market-data provider covering stocks (US, HK, China A-shares, Japan, South Korea, India), forex, crypto (30+ exchanges), and commodities/futures. Offers REST/HTTP and WebSocket streaming APIs with API-key authentication, plus a local MCP server and llms.txt documentation surface.

## APIs

- **Infoway REST/HTTP Market Data API** — GET/POST endpoints for symbol lists, basic info, trading days/hours, batch K-line (candlestick) queries, trades, and market depth across stocks, crypto, forex, and futures. API-key header auth; response envelope {ret, msg, traceId, data}. (`https://data.infoway.io`)
- **Infoway WebSocket Streaming API** — Persistent WebSocket connection for real-time candlesticks, trades, market depth, and news subscriptions with millisecond-latency push. API-key authenticated. (`https://data.infoway.io`)

> Provider exposes a REST/HTTP API and a WebSocket streaming API (both API-key auth, host data.infoway.io) plus an llms.txt at https://docs.infoway.io/llms.txt (GitBook also serves per-page .md and a ?ask= query mechanism). An MCP server (infoway-mcp-server, 17 tools) runs LOCALLY over stdio (PyPI: infoway-mcp-server; source: github.com/infoway-api/infoway-mcp-server) — it is not a hosted/remote endpoint. Its documentation page is at https://docs.infoway.io/sdk-and-tools/mcp-server.md. Official Python, Node.js, and Java SDKs are published. The submitted APIs.json baseURL of https://infoway.io is the marketing host; the actual API host is https://data.infoway.io. agent_native=true due to the public llms.txt.
